AYUSH SHARMA — AI FILMMAKER PORTFOLIO
=====================================

Files
  index.html   the whole website (one file: design, text, scripts)
  previews/    optional hover-preview clips (see previews/README.txt)

HOST IT (free, 2 minutes) — any one option:

1) Netlify Drop (easiest)
   - Unzip this file.
   - Open https://app.netlify.com/drop
   - Drag the "ayush-portfolio" folder onto the page. Done — you get a live link.
   - Sign in to keep it and rename the site (e.g. ayush-sharma.netlify.app).

2) Vercel
   - https://vercel.com/new -> deploy the "ayush-portfolio" folder (no build settings needed).

3) Firebase (your old portfolio: ayush-sharma-portfolio.web.app)
   - Replace the files in your Firebase "public" folder with these, then run:  firebase deploy

4) GitHub Pages
   - New repo -> upload index.html + previews/ -> Settings > Pages -> Deploy from branch (main, root).

Notes
  - Videos play inside the site (Instagram + Google Drive players) once hosted.
  - Google Drive videos must be shared as "Anyone with the link".
  - Opening index.html by double-click also works for a quick local check.
